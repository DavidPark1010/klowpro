# Klow Pro

Vite + React + TypeScript + Tailwind CSS v4 기반 디자인 스타터.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속하면 화면이 보입니다.

## 스택

- **Vite 6** — 빠른 개발 서버 / HMR
- **React 18 + TypeScript**
- **Tailwind CSS v4** — `@tailwindcss/vite` 플러그인 방식

## 폴더 구조

```
src/
  main.tsx     # 진입점
  App.tsx      # 디자인 시안 시작 지점 — 여기를 수정하세요
  index.css    # Tailwind import
```

## 스크립트

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 결과 미리보기 |
